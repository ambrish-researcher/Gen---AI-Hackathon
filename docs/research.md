# Research scope

Hypothesis: reconciling conflicting evidence and revalidating retained outcomes may improve task reliability relative to otherwise comparable controllers without those mechanisms. This release provides an evaluation harness, not a proof of that hypothesis.

## ASPIRE sources reviewed

Official NVIDIA repository, pinned to `fa00f0ef2bc1d91d594b9aa502c22133c9f538f7`:

- [README](https://github.com/NVlabs/ASPIRE/blob/fa00f0ef2bc1d91d594b9aa502c22133c9f538f7/README.md)
- [LIBERO-Pro runbook](https://github.com/NVlabs/ASPIRE/blob/fa00f0ef2bc1d91d594b9aa502c22133c9f538f7/docs/libero-pro.md)
- Paper linked by that README: [ASPIRE: Agentic /Skills Discovery for Robotics](https://arxiv.org/abs/2607.00272). The paper itself was not retrieved in this task.

The README describes continual skill refinement rather than gradient descent, a repository of sensorimotor skills, iterative-debugging and evolutionary-search workflows, evaluation on LIBERO-Pro, Robosuite and BEHAVIOR-1K, and selected real-robot examples. Reported benchmark figures are the authors' results, not reproduced PRAXIS measurements; we do not reuse those figures in our charts.

The LIBERO-Pro runbook distinguishes structural validation from task-completion benchmarks, describes 80 required suite/task pairs, calibrated RGB-D and 20Hz actions, and documents saved-state seed wrapping versus procedural seeded placement. It explicitly warns that selected examples do not establish broad robustness. These distinctions inform PRAXIS's separation of smoke tests, mission outcomes and bounded experimental claims.

We have not established that ASPIRE lacks provenance, reconciliation, safety or memory. PRAXIS is independent and is not an NVIDIA product, successor or ASPIRE performance improvement.

## PRAXIS implemented experiments

`experiments/*-seed42.json` contain actual traces and measurements generated by `scripts/benchmark.py`: six scenarios × five tasks × four policies = 120 recorded trial outcomes. Seed 42 chooses a sequence from three fixed station targets; repeated seeds do not generate new warehouse layouts. The multi-delivery scenario uses a single fixed mission. Initial obstacle observations are global for PRAXIS. Unexpected obstacles are inserted on the reference route before motion; the Studio separately supports insertion during execution.

Static A* retains its original occupancy map and safely stops at an unmodeled obstruction. Reactive A* observes its next blocked cell, stops and replans. PRAXIS incorporates sensor notifications proactively. Every policy retains the same collision guard, map restrictions, cargo checks and verifier. PRAXIS and the reactive baseline use the same speed for mechanism comparisons; the separate v2 parameter candidate intentionally changes speed and cannot establish a reasoning improvement.

At seed 42 in the unexpected-obstacle fixture, static A* verified 0/5, reactive A* 5/5, and PRAXIS 5/5 with zero collisions across policies. This demonstrates the value of replanning over a static policy in this constructed fixture, not that reconciliation or memory improves over reactive planning. Conflict-only trials need not traverse the contradictory cell, so success there does not establish a conflict-handling advantage. Memory is retrieved/revalidated but has no established causal success benefit when current occupancy already reveals all obstacles.

Further work: independently randomized layouts, controlled observation freshness/occlusion, matched information budgets, ablation of reconciliation and memory, multiple seeds, uncertainty intervals, robustness and failure analysis. Do not compare these kinematic navigation results directly with ASPIRE manipulation benchmarks.
